# 요구사항 정의서 목록

이 문서는 Yeolo 프로젝트의 요구사항 요약 목록입니다. 상세한 설명 및 관련 인수 기준 세부는 각 요구사항 ID 링크의 개별 문서에서 확인할 수 있습니다.

---

| 요구사항 ID | 요구사항 명 | 설명 | 인수기준 |
| :--- | :--- | :--- | :--- |
| [REQ-1](./REQ-1.md) | OAuth 로그인 | 사용자가 OAuth를 통해 로그인하고 서비스 진입 상태를 관리한다. | 사용자는 OAuth 로그인을 완료한 뒤 Intro 화면으로 이동할 수 있고, 로그인 실패 시 재시도 또는 오류 안내를 확인할 수 있다. |

| [REQ-3](./REQ-3.md) | 개인 취향 분석 | 사용자 데이터(사진)을 바탕으로 여행 취향 특징을 추출하고 저장한다. | 사용자 사진을 바탕으로 취향 분석을 시작하고, 결과를 저장하며, 동의 없이 분석하지 않는다. |
| [REQ-4](./REQ-4.md) | 취향 기반 여행 코스 생성 | 개인 취향, 여행 조건(지역, 일정, 예산)을 기반으로 이동·예산·시간 제약을 고려한 코스를 생성한다. | 사용자는 서버에서 제공하는 국가/도시 목록을 기반으로 여행 지역을 선택할 수 있다. 여행 조건 입력 후 장소·시간대·이동 순서·예상 예산이 포함된 개인 맞춤형 코스와 추천 이유가 표시된다. |
| [REQ-5](./REQ-5.md) | 여행 코스 상세 확인 | 생성된 여행 코스를 타임라인으로 확인하고 공유할 수 있게 한다. | 일정이 날짜·시간·장소·이동·예산 단위로 표시되고, 상세 정보와 추천 이유를 확인하며 재접근할 수 있다. |
| [REQ-6](./REQ-6.md) | 여행 코스 확인 내 친구 초대 | 생성된 여행 코스 확인 화면에서 친구를 초대해 함께 코스를 확인하거나 공유할 수 있게 한다. | 사용자는 코스 확인 화면에서 친구 초대 액션을 실행할 수 있고, 초대받은 사용자의 경로 목록에 공유된 경로가 저장된다. 초대 실패 시 안내 메시지를 확인할 수 있다. |
| [REQ-7](./REQ-7.md) | 여행 코스 목록 및 관리 | 사용자가 저장했거나 공유받은 여행 코스 목록을 조회하고 필요 없는 코스를 삭제할 수 있게 한다. | 사용자는 저장된 여행 코스 목록을 조회하고, 선택한 코스를 상세 확인하거나 삭제할 수 있다. 삭제된 코스는 목록에서 제거되며 삭제 실패 시 안내가 표시된다. |
| [REQ-8](./REQ-8.md) | 개인정보 동의 및 데이터 관리 | 사용자 데이터 수집·분석 전 명확한 동의 절차를 제공한다. | 사용자는 사진 데이터 분석 전에 명시적으로 동의해야 하며, 동의하지 않으면 분석을 진행하지 않는다. |
| [REQ-9](./REQ-9.md) | MBTI 기반 여행 코스 생성 | MBTI, 여행 조건(지역, 일정, 예산)을 기반으로 이동·예산·시간 제약을 고려한 코스를 생성한다. | 사용자는 서버에서 제공하는 국가/도시 목록을 기반으로 여행 지역을 선택할 수 있다. 여행 조건 입력 후 장소·시간대·이동 순서·예상 예산이 포함된 MBTI 기반 맞춤형 코스와 추천 이유가 표시된다. |
| [REQ-10](./REQ-10.md) | 예약 연동 및 제휴 링크 | 추천 일정 내 숙소·항공·액티비티 예약 페이지로 연결되는 제휴 링크를 제공한다. | 일정 상세에서 관련 예약 링크를 확인하고 외부 예약 페이지로 이동하며, 미제공 상품에는 대체 안내가 표시된다. |
| [REQ-11](./REQ-11.md) | 마이페이지 | 사용자 취향 분석 결과, 계정 관리 등 부가적인 기능을 관리한다. | 프로필과 여행 기록을 조회하고, 데이터 연동/동의 상태를 변경하며, 저장된 코스와 앨범으로 이동할 수 있다. |
| [REQ-12](./REQ-12.md) | AI 추천 서버 운영 안정성 | LLM 성향 분석과 경로 최적화 로직을 분리하고 캐시·호출량·리소스를 관리해 비용과 장애 리스크를 낮춘다. | LLM 분석, 후보 생성, 제약 검증 단계가 구분되고, 캐시 전략 적용이 가능하며, 오류 시 기본 추천 또는 안내가 제공된다. |
| [REQ-13](./REQ-13.md) | 여행 후 공동 앨범 | 여행 사진을 업로드하거나 연동해 시간·위치 기반으로 분류하고 그룹 공동 앨범으로 공유한다. | 여행별 앨범에 접근할 수 있고, 사진이 날짜 또는 위치 기준으로 분류되며, 그룹 참여자가 공동 앨범에 사진을 추가·조회할 수 있다. |
| [REQ-14](./REQ-14.md) | AI 앨범 자동 정리 | AI 이미지 처리로 베스트 샷 추천, 중복 제거, 음식·풍경·인물 등 테마별 분류를 지원한다. | AI 자동 정리를 실행하면 중복 후보·베스트 샷·테마 분류 결과가 표시되고 사용자가 결과를 수정할 수 있다. |
| [REQ-15](./REQ-15.md) | 그룹 취향 교차 분석 추천 | 다수 구성원의 성향을 종합해 그룹 전체 만족도를 최대화하는 여행 코스를 추천한다. | 구성원 초대와 성향 반영이 가능하고, 선호 충돌 시 타협 근거 또는 대안이 표시되며, 그룹 코스가 저장된다. |

| [REQ-17](./REQ-17.md) | 그룹 톡방 및 일정 조율 | 그룹별 대화 공간을 제공해 여행 계획 조율과 추천 코스 논의를 지원한다. | 그룹 단위 대화 공간이 생성되고, 참여자가 메시지를 작성·조회하며, 일정 또는 추천 코스와 연결된 맥락을 확인할 수 있다. |
