# [REQ-11] Zero-Touch 개인 성향 분석

## 상세 요구사항

- 사용자는 동의 기반 행동 데이터(사진, 캘린더)를 제공할 수 있어야 한다.
- 시스템은 수집 가능한 데이터를 관심사, 활동 성향, 선호 분위기 등 여행 성향 특징으로 변환해 저장해야 한다.
- 데이터 부족 시 간단 설문으로 대체 입력을 제공해야 한다.

## Acceptance Criteria

- 사용자가 데이터 연동 또는 최소 설문 중 하나를 선택해 성향 분석을 시작할 수 있다.
- 분석 결과가 사용자 프로필에 저장되고 이후 추천 요청에 재사용된다.
- 개인정보 수집·활용 동의가 완료되지 않으면 외부/비정형 데이터 분석을 수행하지 않는다.
