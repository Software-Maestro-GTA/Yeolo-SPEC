# [REQ-6] AI 추천 서버 운영 안정성

## 상세 요구사항

- 추천 서버는 LLM 기반 성향 분석과 경로 최적화/제약 처리 로직을 분리해 안정적으로 운영되어야 한다.
- LLM 및 클라우드 비용 증가에 대비해 호출량, 캐시, 리소스 사용량을 관리해야 한다.
- MVP 단계에서는 제한된 데이터 소스와 지역 범위로 검증 가능해야 한다.

## Acceptance Criteria

- 추천 요청 처리 과정에서 LLM 분석, 후보 생성, 제약 검증 단계가 구분된다.
- 동일 조건 또는 유사 요청에 대한 재사용/캐시 전략이 적용 가능하다.
- 오류 발생 시 기본 추천 또는 사용자 안내가 제공된다.
