# [FUN-1] 동의 기반 행동 데이터 연동 및 여행 성향 분석

## 상세 기능 설명 및 정책

- 사용자가 사진/캘린더 등 행동 데이터 연동에 동의하면, 시스템은 수집 가능한 데이터를 기반으로 관심사, 활동 성향, 선호 분위기 등 여행 성향 특징을 추출한다.
- 개인정보 수집·활용 동의가 완료되지 않은 경우 외부/비정형 데이터 분석 요청을 수행하지 않는다.
- 데이터가 부족하거나 연동을 원하지 않는 경우 최소 설문 입력 플로우로 대체한다.

## 예외 처리

- 동의 미완료: 분석 시작 버튼 비활성화 또는 동의 안내 메시지 노출
- 연동 실패: 재시도 안내 및 최소 설문으로 대체할 수 있는 선택지 제공
- 분석 데이터 부족: 최소 설문 화면으로 전환
