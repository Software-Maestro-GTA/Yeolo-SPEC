# [FUN-8] MBTI 기반 여행 코스 생성

## 기능 개요

- **구현 범위**: Frontend, Backend, AI
- **연결된 UI 화면**: 여행 코스 생성 화면, 여행 코스 확인 화면
- **관련 요구사항**: 1개 연동

## 상세 내용 및 예외 처리

사용자가 입력한 MBTI와 서버에서 조회한 국가/도시, 일정, 예산 조건을 기반으로 맞춤형 여행 코스를 생성한다. 여행 코스 생성 화면에서 국가 목록과 선택한 국가의 도시 목록을 조회해 지역 선택에 사용한다. 결과에는 장소, 시간대, 이동 순서, 예상 예산, MBTI 기반 추천 이유가 포함되어야 한다. 국가/도시 조회 실패, MBTI 또는 여행 조건 누락, 추천 생성 실패 시 입력 안내 또는 재시도 안내를 제공한다.
