# [FUN-2] AI 개인 맞춤형 여행 코스 생성 알고리즘

## 상세 기능 설명 및 정책

- 시스템은 사용자 성향, 여행 조건, 장소 데이터를 매칭해 맞춤형 여행 코스를 생성한다.
- 이동 시간, 예산, 영업시간, 선호도 제약 조건을 반영해 장소와 시간대, 이동 순서를 구성한다.
- 추천 결과에는 각 장소 또는 일정 구간별 추천 이유와 핵심 추천 포인트를 포함한다.

## 예외 처리

- 조건을 만족하는 장소 부족: 조건 완화 안내 또는 대체 장소 추천
- 외부 장소 데이터 조회 실패: 캐시 데이터 또는 기본 추천 결과 사용
- AI 응답 실패/지연: 로딩 상태 유지 후 재시도 안내
