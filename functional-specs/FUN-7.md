# [FUN-7] 이전 생성 코스 목록 확인

## 상세 기능 설명 및 정책

- 사용자는 이전에 생성한 여행 코스 목록을 확인할 수 있어야 한다.
- 목록에는 코스 제목, 대표 지역, 여행 시작일, 총 여행 일수가 표시된다.
- 사용자가 목록에서 코스를 선택하면 해당 코스 상세 확인 화면으로 이동한다.
- 목록은 최신 생성순으로 표시하고, 필요 시 지역/기간 기준 필터를 추가할 수 있도록 확장 가능하게 설계한다.

## 예외 처리

- 생성된 코스가 없는 경우: 빈 상태 화면과 코스 생성 CTA를 노출한다.
- 목록 조회 실패: 재시도 버튼과 오류 메시지를 노출한다.
- 삭제되었거나 접근 권한이 없는 코스 선택 시: 접근 불가 안내 후 목록으로 되돌린다.
