# [FUN-9] 여행 코스 목록 조회 및 관리

## 기능 개요

- **구현 범위**: Frontend, Backend
- **연결된 UI 화면**: 여행 코스 목록 화면, 여행 코스 확인 화면
- **관련 요구사항**: 1개 연동

## 상세 내용 및 예외 처리

사용자가 저장했거나 공유받은 여행 코스 목록을 조회하고, 선택한 코스의 상세 화면으로 이동한다. 사용자가 저장된 여행 코스를 삭제하면 서버에 삭제 요청을 보내고 목록에서 제거한다. 목록이 비어 있으면 빈 상태 안내를 표시하고, 조회 실패·삭제 실패·권한 없음 상태에서는 안내 메시지를 제공한다.
