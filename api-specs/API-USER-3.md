## 4. 상세 내용 및 예외 케이스

## 기능

로그인한 사용자의 저장된 선호 언어를 조회한다. 사용자 식별은 Authorization 헤더의 액세스 토큰을 기준으로 한다.


## 응답 규칙

- `data.language`: 사용자의 선호 언어 코드. BCP 47 형식의 서비스 지원 코드로 반환한다.
- `ko`는 한국어 응답 예시이며, 전체 지원 언어 목록은 별도 확정한다.
- 언어 설정이 없는 경우 서비스 기본 언어를 반환한다. 기본값은 `ko`를 제안하며, 적용 전 확정이 필요하다.
- 조회 요청은 저장된 설정을 변경하지 않는다.

## 언어 헤더 정책 (제안)

- 요청 헤더 `Accept-Language`는 선택 사항이며, 이번 응답의 사용자 표시용 `message` 언어를 지정한다. 예: `ko`, `en`, `ko-KR,ko;q=0.9,en;q=0.8`. 예시가 전체 지원 언어 목록을 의미하지는 않는다.
- 응답 언어는 헤더의 지원 언어 중 우선순위가 높은 언어 → 저장된 선호 언어 → 서비스 기본 언어 순으로 결정한다. 지역 코드 매칭 및 지원 언어 목록은 별도 확정한다.
- 헤더가 없거나 매칭되는 지원 언어가 없으면 저장된 선호 언어 또는 서비스 기본 언어로 폴백한다. 헤더의 미지원 언어만으로 `400`을 반환하지 않는다.
- 헤더는 계정 설정을 변경하지 않는다. `data.language`는 기존 조회 규칙에 따른 선호 언어이며, 응답 메시지 언어와 다를 수 있다.
- 응답 헤더 `Content-Language`에는 실제 메시지에 적용한 언어 코드를 반환한다. 성공·실패 응답에 동일한 정책을 적용하며, 사용자를 식별할 수 없는 인증 실패 응답은 요청 헤더 또는 기본 언어를 사용한다.
- 현재 성공·실패 응답 속성의 한국어 문구는 `ko` 응답 예시다.

## 적용 범위

계정별 선호 언어 조회를 담당한다. UI 번역 리소스 및 콘텐츠·AI 응답의 언어 적용은 별도 정책으로 정의한다.
