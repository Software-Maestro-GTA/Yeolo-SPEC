# [DOM-7] 아고다 파트너스 연동 프로세스

## 목적

여행 코스 확인 화면에서 사용자가 아고다 파트너스 제휴 링크를 통해 호텔 또는 항공 예약 페이지로 이동할 수 있도록 한다.

Yeolo는 직접 예약·결제를 처리하지 않고, 아고다 웹 페이지로 이동하는 예약 링크만 제공한다.


## 기본 방향

- 예약은 아고다에서 진행한다.
- 결제, 취소, 환불, 예약 변경은 아고다 정책을 따른다.
- Yeolo는 여행 코스에 맞는 호텔/항공 예약 링크를 제공한다.
- 사용자가 제휴 링크를 통해 예약하면 아고다 파트너스 정책에 따라 수수료가 발생할 수 있다.
- 아고다 파트너 ID와 추적 파라미터는 서버에서 관리한다.

## 사용자 플로우

```plain text
여행 코스 확인 화면
→ 숙소/항공권 예약 버튼 선택
→ 서버에서 아고다 제휴 링크 제공
→ 외부 브라우저로 아고다 페이지 이동
→ 사용자가 아고다에서 예약·결제 진행
```


## 화면 처리

여행 코스 확인 화면에 예약 CTA를 제공한다.

```plain text
숙소 예약하기
항공권 예약하기
```


## 서버 역할

서버는 다음을 담당한다.

- 여행 코스의 도시와 일정 정보 확인
- 아고다 제휴 링크 생성 또는 조회
- 아고다 파트너 ID 및 추적 파라미터 관리
- 필요 시 예약 링크 클릭 로그 저장
- 예약 링크 제공 가능 여부 판단
앱은 아고다 제휴 파라미터를 직접 만들지 않고, 서버가 반환한 링크만 사용한다.


## 예외 처리


### 예약 링크가 없는 경우

```plain text
현재 이 여행지의 예약 링크를 제공할 수 없습니다.
```


### 아고다 페이지 이동 실패

```plain text
예약 페이지를 열 수 없습니다. 잠시 후 다시 시도해주세요.
```
