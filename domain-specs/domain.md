# 데이터 및 도메인 목록

이 문서는 Yeolo 프로젝트의 핵심 데이터 모델 및 도메인 목록입니다. 세부 도메인 스펙(필드 정의, 저장 목적, 데이터베이스 컬럼 스펙, JSON 예시)은 각 Domain ID 링크의 개별 문서에서 확인할 수 있습니다.

---

## 도메인 목록

| Domain ID           | 도메인 명                                                    | 설명                                                                                |
| :------------------ | :----------------------------------------------------------- | :---------------------------------------------------------------------------------- |
| [DOM-1](./DOM-2.md) | 성향 정보 (Taste Profile)                                    | 개인의 설문 응답 또는 행동 데이터를 바탕으로 정규화된 여행 취향 선호 점수 분석 정보 |
| [DOM-2](./DOM-3.md) | 코스 정보 (Course Recommendation)                            | 사용자의 여행 성향 및 제약 조건에 따라 일자별·순서별로 구성된 AI 추천 여정 정보     |
| [DOM-3](./DOM-1.md) | 사용자 정보 (User)                                           | 로그인 사용자 식별 및 다른 도메인의 소유주 연결을 위한 도메인                       |
| [DOM-5](./DOM-4.md) | 이미지 메타데이터 전처리 정보 (Image Metadata Preprocessing) | 사진의 EXIF 좌표와 시간을 Reverse Geocode 및 시간대 맥락 정보로 가공한 전처리 정보  |
