# 코스 생성 프로세스


## 목적

사용자의 MBTI, 취향 정보, 여행 조건을 바탕으로 여행 코스를 생성한다.

BE 서버는 사용자 선호 정보와 여행 조건을 AI 서버에 전달하고, AI 서버는 이를 기반으로 일자별 여행 코스를 생성해 반환한다.


## 전체 흐름

```plain text
사용자 선호 정보 + 여행 조건
→ AI 서버 요청
→ LLM 기반 코스 생성
→ 일정/동선/비용 구조화
→ SSE로 진행 상태 및 결과 반환
```


## 단계별 프로세스


### 1. 요청 수신

AI 서버는 다음 정보를 전달받는다.

- `userId`
- `mbti`
- `tasteProfile`
- `tripCondition`
  - 여행 국가
  - 여행 도시
  - 시작일
  - 여행 일수
  - 예산 타입

### 2. 입력 데이터 구성

AI 서버는 취향 정보와 여행 조건을 코스 생성 프롬프트에 맞게 정리한다.

여기에는 다음 요소가 포함된다.

- 여행 목적
- 일정 밀도
- 선호 장소 유형
- 활동 취향
- 소비 성향
- 음식 취향
- 여행 국가/도시
- 여행 일수
- 예산 조건

### 3. LLM 코스 생성

LLM은 사용자 선호와 여행 조건을 바탕으로 코스를 생성한다.

생성 시 반영하는 핵심 기준:

- 일정 밀도에 맞는 하루 방문 장소 수 조정
- 비효율적인 왕복 이동 최소화
- 이동 수단과 이동 시간 고려
- 예산 타입에 맞는 비용 수준 반영
- 코스 전체 추천 이유와 장소별 추천 이유 생성

### 4. 구조화된 코스 조립

생성 결과는 정해진 코스 스키마에 맞춰 정리된다.

주요 결과:

- 코스 제목
- 여행 국가/도시
- 시작일
- 총 일수
- 태그
- 추천 이유
- 일자별 일정
  - 방문 순서
  - 장소명
  - 카테고리
  - 도착 시간
  - 체류 시간
  - 이동 수단
  - 이동 시간
  - 예상 비용
  - 추천 이유
